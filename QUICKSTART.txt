"""
Guia rápido de instalação e uso
"""

# INSTALAÇÃO RÁPIDA

## Passo 1: Instalar dependências
pip install -r requirements.txt

# Nota: rpy2 requer R instalado. Se não tiver R:
pip install -r requirements.txt --ignore-installed rpy2

## Passo 2 (Opcional): Instalar R para melhor qualidade de gráficos
# Windows: https://cran.r-project.org/
# Depois instale os pacotes R:
# R
# > install.packages(c("ggplot2", "tidyr", "dplyr", "GGally", "scales"))
# > q()


# USO RÁPIDO

## Terminal 1: Iniciar simulador LSL
python simulador_lsl_emg.py

## Terminal 2: Executar aplicação
python Grafico.py

## Na interface:
# Clique em "⬇️ RECARREGAR DE LSL" para capturar dados


# TESTE DE INTEGRAÇÃO

python teste_lsl_integracao.py


# TROUBLESHOOTING

## Se der erro "x not found"
pip install x

## Se R não funcionar
# A aplicação usa automaticamente fallback em matplotlib
# Gráficos serão gerados em Python

## Se houver erro de "Nenhum stream LSL encontrado"
1. Verifique se simulador_lsl_emg.py está rodando
2. Verifique se não há firewall bloqueando localhost

# FLUXO DE DADOS

Simulador LSL
    ↓ (EMG Stream + EMG_Processado Stream)
Aplicação Grafico.py
    ↓ (Botão "RECARREGAR DE LSL")
Captura de dados 
    ↓
Cálculo de métricas (RMS, Freq. Mediana, ZCR, Waveform Length)
    ↓
Geração de gráficos (R ou matplotlib)
    ↓
Visualização na interface

# NOTAS IMPORTANTES

- Cada clique em "RECARREGAR DE LSL" captura 5 segundos de novo dados
- Os dados são armazenados em output/metricas_canais.csv
- A aplicação aguarda 3 segundos por streams LSL antes de timeout
- O simulador envia dados continuamente até ser interrompido (Ctrl+C)
- Recomenda-se deixar o simulador rodando enquanto testa a interface
